🔥 Red Flame Restaurant

A premium restaurant website concept built around bold visual identity, editorial storytelling, menu discovery, and a smooth customer journey from discovering the brand to making a reservation.

Red Flame was designed as a complete digital experience rather than a simple restaurant landing page — combining custom art direction, responsive layouts, purposeful motion, and direct reservation/contact flows.

✨ Overview

Red Flame is a multi-page restaurant website concept created to explore how a strong food brand can translate its personality into a modern digital experience.

The site focuses on three things:

- Brand — establishing a distinctive restaurant identity through typography, imagery, color, texture, and layout.
- Experience — guiding visitors through the restaurant story, menu, reviews, and contact information.
- Conversion — making it easy for visitors to reach the restaurant and request a reservation.

🧭 Experience Flow

The website is structured around a simple customer journey:

Discover → Explore → Browse Menu → Learn the Story → Build Trust → Contact / Reserve

Each page contributes to that journey rather than functioning as an isolated static page.

📄 Pages

Page| Purpose
Home| Introduces the restaurant and establishes the brand
Menu| Presents the restaurant's food offering
About| Tells the Red Flame story and communicates the brand's values
Reviews| Builds trust through customer feedback
Contact| Provides contact and reservation pathways

🎨 Design Direction

Red Flame was designed around a bold, editorial restaurant aesthetic rather than a conventional restaurant template.

The visual system combines:

- Expressive editorial typography
- Clean modern UI typography
- Strong image composition
- High-contrast layouts
- Grain and texture
- Flame-inspired visual language
- Oversized headlines
- Branded graphic elements
- Controlled animation and movement

The goal was to create an identity that feels hot, confident, contemporary, and memorable without relying on excessive visual effects.

🛠️ Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Responsive Web Design
- Intersection Observer API
- Vercel

No frontend framework is required.

The project was intentionally built with standard web technologies to demonstrate that polished interactions and strong visual experiences can be created without depending on a large JavaScript framework.

♿ Accessibility & UX

Accessibility and user preferences were considered throughout the implementation.

The project includes:

- Accessible navigation states
- Descriptive image attributes
- Keyboard-friendly interactive elements
- Reduced-motion handling
- Responsive layouts across screen sizes
- Clear interaction states
- Progressive image loading

Animations are treated as enhancement rather than a requirement for using the website.

⚡ Performance Considerations

The implementation includes several frontend performance considerations:

- Image lazy loading
- Hero image prioritization
- Explicit image dimensions
- Font preconnection
- Lightweight vanilla JavaScript
- CSS-based visual effects where appropriate
- Reduced-motion handling

The goal was to balance visual richness with a lightweight frontend implementation.

📱 Responsive Design

Red Flame was designed to work across:

- Mobile devices
- Tablets
- Laptops
- Desktop displays

Layouts, navigation, typography, imagery, and interactive elements adapt to different viewport sizes rather than treating mobile as a separate experience.

💻 Running Locally

Move into the project directory:

Then open "index.html" in a browser or run the project through a local development server.

🌐 Deployment

The project is deployed on Vercel.

The frontend can be deployed as a static site without a separate backend or build pipeline.

📌 Project Scope

Red Flame is a frontend restaurant website concept.

The current implementation does not include:

- A restaurant database
- Online food ordering
- Payment processing
- Server-side reservation management
- Real-time table availability
- Customer accounts
- Restaurant administration tools
- Automated reservation confirmation

The reservation/contact experience is designed as a frontend conversion flow with direct communication handoff.
